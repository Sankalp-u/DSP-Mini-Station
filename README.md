# Nexus DSP Platform

Interactive DSP + Control System Analysis Platform.

## Features
- Time-domain signal visualization
- FFT spectrum analyzer
- Laplace & stability analysis
- Pole-zero map
- Bode plot
- Root locus
- AI signal assistant

## Tech Stack
React + Vite  
Node.js + Express  
TailwindCSS  
DSP Algorithms (FFT, Laplace)

## Run Locally

### Backend
cd server
npm install
node server.js

### Frontend
cd client
npm install
npm run dev
